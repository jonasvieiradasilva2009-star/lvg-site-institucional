# Arquivos-fonte da marca

- `lvg-logo-original.webp` — arquivo da logo recebido (versão enviada na conversa de desenvolvimento).
- `lvg-logo-trimmed.png` — mesma logo, apenas com as margens transparentes recortadas (sem nenhuma alteração de desenho).
- `lvg-symbol-trimmed.png` — recorte somente das letras "LVG", usado para gerar os favicons.

Os arquivos servidos pelo site ficam em `public/brand/`, `public/icons/`, `public/favicon.ico` e `public/og/`.
Quando o arquivo definitivo da logo (de preferência SVG ou PNG em alta resolução) estiver disponível,
siga a seção **Como substituir a logo** do README principal.
